# UI / UX Rules

## Main shell

Left navigation:
- Mein Tag
- Abschlussprozess
- Kommunikation
- Statusbericht
- Administration (admin only)

Default:
- Mein Tag

## Top bar

Maintain:
- company
- project
- search
- deadline context
- role/profile
- optional skin choice

## Task workspace

Current task workspace uses tabs such as:
- Anleitung
- Vorjahr
- Arbeitsbereich
- Notizen
- E-Mail
- Kommunikation
- Prüfung

KAI/KIRA should know the current task and active tab.

## KAI/KIRA entry

V7+ direction:
- global floating/compact KAI/KIRA control
- usable even inside an open task
- context-sensitive label/context
- opens large bottom drawer
- close/minimize
- KAI/KIRA toggle
- chat history
- quick prompts
- input box
- progress while response is being generated
- token/EUR usage estimate
- memory indicators

## KAI/KIRA response style

Default:
- concise
- professional
- specific
- immediately useful
- facts separated from recommendations

Avoid:
- generic textbook answers
- invented project deadlines
- long boilerplate responses

If the user asks for detail, expand.

## Special tool rendering

The following must not be treated like plain task-modal content:
- 2.1
- 2.2
- 2.4
- 3.17
- 4.4

They have specialized tool content.

## Accordions

Historical preference:
- accordion structures start collapsed
- provide expand all / collapse all where useful

## Numbers / locale

Use German locale conventions in user-facing finance UI where applicable.

## Look and feel

Maintain a professional finance/audit product:
- restrained
- legible
- high information density without clutter
- LUMINA green as default
- side navigation dark green

Do not redesign for novelty.
