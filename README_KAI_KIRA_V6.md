# LUMINA KAI/KIRA V6

V6 verbessert die Bedienung des persönlichen KI-Sparrings in **Mein Tag**.

## UX-Konzept

- Die rechte Spalte enthält nur noch eine kompakte KAI/KIRA-Karte mit aktuellem Arbeitsvorschlag und kurzer Vorschau.
- Über **Mit KAI/KIRA sprechen** öffnet sich ein großer Bottom-Drawer im zentralen Arbeitsbereich.
- Der Drawer ist breit genug für fachliche Dialoge, Listen und Nachweise, hält die Aufgabenansicht im Hintergrund sichtbar und lässt sich per X oder Klick auf den Hintergrund schließen.
- KAI/KIRA, Schnellfragen, Chatverlauf, Eingabefeld und serverseitig autorisierter Tageskontext bleiben unverändert erhalten.
- KAI/KIRA führen weiterhin keine automatische Status- oder Datenänderung aus.
